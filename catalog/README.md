# Catálogo SOMOSUM — packs offline

Manifests JSON usados pelo app SOMOSUM (Loja de Plugins, hinários, mídia).

| Pasta | Uso no app |
|-------|------------|
| `plugins/` | Ferramentas → Loja de Plugins |
| `hinarios/` | Biblioteca → Escolher hinários |
| `media/` | Mídia → Fundos padrão |

Os arquivos ZIP ficam no **GitHub Release** `packs-8.7.8` (tag alinhada ao campo `cdnBaseUrl` nos manifests).

Publicado a partir do repositório principal SOMOSUM via `node scripts/publish-pack-catalog.mjs`.
